# RoadMed Hub (v1, static)
Curated directory for travel nurses & medical device sales reps. Plain static HTML generated by `build.py` from `listings.json` (no dependencies).

## Local
    python3 build.py && cd dist && python3 -m http.server 8123   # http://localhost:8123

Edit listings in `listings.json`: [name, url, category, description, "nurses,reps"]. Categories are in `build.py` (CATS).

## Deploy to Vercel
1. Push this folder to a GitHub repo.
2. vercel.com → New Project → import repo. `vercel.json` sets build `python3 build.py`, output `dist`.
   (Or CLI: `npm i -g vercel && vercel --prod`. Alternatively commit `dist/` and set Framework "Other", output `dist`, no build command.)
3. Add your domain; update `BASE` in build.py (canonical URLs + sitemap) and rebuild.
